# K13 — 原创方法及有限合成案例

来源理论需要逐命题核证；本文件不作真实教育效果或独立资格结论。

## K13.01.01 / K13.01.01.RQ01

**方法：** 观察榜样的机会、注意与后续独立表现分开记录。

**合成输入：** 教师演示三步，学生观看完整但新任务第二步错；另学生未观看却完成。

**判别与边界：** 观看不等于习得，未观看不等于缺能力；保留不同来源经验及独立表现。

## K13.01.02 / K13.01.02.RQ01

**方法：** 模仿精度与规则理解、迁移分别设计任务。

**合成输入：** 学生逐步复现同样操作；变化材料后不知选哪个步骤。

**判别与边界：** 同样任务模仿成功，迁移未建立；不是所有理解不足的诊断。

## K13.01.03 / K13.01.03.RQ01

**方法：** 同伴支持记录参与、解释和无帮助新任务表现。

**合成输入：** 同伴提供正确答案后小组满分，独立题一人错。

**判别与边界：** 小组结果与个人结果分别报告；不能从满分推断个人习得。

## K13.01.04 / K13.01.04.RQ01

**方法：** 共同建构记录协商内容、修订、来源和个人可追溯贡献。

**合成输入：** 甲提出解释、乙给反例、丙汇总并修订；另组一人代写全部。

**判别与边界：** 前者有共同修订证据，后者仅共同提交；个人能力需独立观测。

## K13.02.01 / K13.02.01.RQ01

**方法：** 任务表现绑定所用符号、工具、互动和实践环境。

**合成输入：** 同一人使用算盘可正确计算，移除算盘后口算未知；评价目标允许工具。

**判别与边界：** 工具条件下表现有效；不得替换为无工具能力。工具是否构念无关按目标决定。

## K13.02.02 / K13.02.02.RQ01

**方法：** 规范作为参与条件，不当作认知能力。

**合成输入：** 课堂要求主动举手，学习者不举手但独立答题准确。

**判别与边界：** 记录未举手及任务结果；不由规范遵从推断理解或动机。

## K13.02.03 / K13.02.03.RQ01

**方法：** 分离学科内容推理与任务语言要求，保持目标构念。

**合成输入：** 数学目标为比例推理；原题文字难，等价图示题独立正确。

**判别与边界：** 可提出语言负荷竞争解释；需控制等价与提示；不直接断言原题仅语言问题。

## K13.02.04 / K13.02.04.RQ01

**方法：** 依据个人实际经验与偏好调整，禁止从群体身份填充个体属性。

**合成输入：** 两人来自同一社区，一人熟悉交易场景另一人不熟；另有陌生社区但熟悉者。

**判别与边界：** 按实际背景/选择设计例子；不使用文化身份作为规则或推断。

## K13.03.01 / K13.03.01.RQ01

**方法：** 家庭资源和可利用时间与实际互动分开。

**合成输入：** 家中有10本书但无阅读记录；另一家无纸书却有共同读电子书记录。

**判别与边界：** 资源和活动分别计；不能从书本量或家庭类型推断能力。

## K13.03.02 / K13.03.02.RQ01

**方法：** 学校机会以实际课程、可及性、资源与支持为证据。

**合成输入：** 同班一人因网络问题缺两次课，另一人完成全部。

**判别与边界：** 课程名相同不代表同机会；缺席原因非能力，需独立表现。

## K13.03.03 / K13.03.03.RQ01

**方法：** 工作经验用实际任务和版本验证而非工龄代替。

**合成输入：** 工龄5年仅做例行检查，新故障由同事完成。

**判别与边界：** 确认例行操作经验，故障处理未建立；不推断职业资格。

## K13.03.04 / K13.03.04.RQ01

**方法：** 社区资源登记可访问条件、许可、实际使用及目标适配。

**合成输入：** 图书馆开放但通勤单程1小时，学习者仅30分钟。

**判别与边界：** 物理资源存在，计划不可行；可建议经确认的远程替代。

## K13.03.05 / K13.03.05.RQ01

**方法：** 日常学习的证据允许无课程记录，仍核对实际能力。

**合成输入：** 自学修理后独立完成安全模拟任务，无结业证书。

**判别与边界：** 记录该任务独立表现，不能由无证书否定学习；真实资格另审。

## K13.04.01 / K13.04.01.RQ01

**方法：** 可用时间、实际参与、有效操作及结果分离。

**合成输入：** 预算30分钟；计划20+20分钟；实际10分钟专注且新题正确。

**判别与边界：** 计划超预算10分钟；实际时间不等于一般效果；仅本次新题表现。

## K13.04.02 / K13.04.02.RQ01

**方法：** 技术可及性先于知识缺口推断。

**合成输入：** 在线任务提交失败因断网，离线同构念独立完成。

**判别与边界：** 线上无效/未观测，离线为证据候选；不把提交失败计为知识错误。

## K13.04.03 / K13.04.03.RQ01

**方法：** 中断和任务条件明确记录，匹配环境才比较表现。

**合成输入：** 两次测验同题型，第二次中断15分钟导致未完成。

**判别与边界：** 第二次测验条件不同，保留中断，不作同条件下降解释。

## K13.04.04 / K13.04.04.RQ01

**方法：** 机会、兴趣、自述目标及实际参与分别记录。

**合成输入：** 本人有兴趣但资源不可访问，另一人可访问但拒绝。

**判别与边界：** 分别记录约束和选择；不自动发起活动或诊断动机。

## K13.05.01 / K13.05.01.RQ01

**方法：** 在线共同体成员、阅读、贡献及独立表现分层。

**合成输入：** 注册100人，10人提问、5人提交作品；其他活动未知。

**判别与边界：** 仅可描述观察到的事件，不能将未发言等同未学习。

## K13.05.02 / K13.05.02.RQ01

**方法：** 共同任务记录角色、协作机制、个人贡献与独立证据。

**合成输入：** 甲分析、乙计算、丙报告；组正确，但甲独立计算未知。

**判别与边界：** 组正确不代表甲计算达标；另行观测所需能力。

## K13.05.03 / K13.05.03.RQ01

**方法：** 组织产出与个体变化是不同分析单位。

**合成输入：** 团队共享检查表后产量增20%，人员替换且设备更新。

**判别与边界：** 组织产出增加，个人学习和因果机制均未知；控制共同变化。

## K13.05.04 / K13.05.04.RQ01

**方法：** 教师支持要绑定具体障碍、适用目标和可撤条件。

**合成输入：** 同一学生一周3次提示仍未独立完成；另一次设备帮助后独立正确。

**判别与边界：** 提示频次非效果；区分构念相关支架和可及性帮助，后续新任务验证。
