# K17 — 原创方法及有限合成案例

来源理论需要逐命题核证；本文件不作真实教育效果或独立资格结论。

## K17.01.01 / K17.01.01.RQ01

**方法：** 区分构念、操作化、指标与竞争解释。

**合成输入：** 拟测独立阅读理解；A读新通知后回答地点和时间，B只测阅读停留时长，C允许答案提示。

**判别与边界：** A为匹配构念的观测候选；B是参与代理，C是辅助表现，不能以时长增长证明理解增长。

## K17.01.02 / K17.01.02.RQ01

**方法：** 预先登记主要结果、时间点、对照与检验；探索性分析另立身份。

**合成输入：** 登记第7日独立回忆；数据后发现第1日显著而第7日不显著。

**判别与边界：** 第7日为主要结果，第1日若未预设只能探索；不得替换主要终点。

## K17.01.03 / K17.01.03.RQ01

**方法：** 目标效应应先定义人群、处理版本、比较、结果及时间。

**合成输入：** 两个班比较间隔与组块，结果为7日独立回忆；一班另得辅导。

**判别与边界：** 欲估计纯间隔效应必须控制辅导或定义联合处理；仅处理标签不足识别。

## K17.01.04 / K17.01.04.RQ01

**方法：** 同时记录效应量、区间、单位、分母、重要阈值及分析地位。

**合成输入：** 两方法平均相差0.2分，95%区间0.1–0.3，预定教育重要差1分。

**判别与边界：** 与零差可区分不等于达到重要差；不得只报告显著。

## K17.02.01 / K17.02.01.RQ01

**方法：** 设计权重是纳入概率倒数；非响应、覆盖和测量仍需证据。

**合成输入：** A层总体100抽10，B层900抽90，各层纳入概率0.1；另B仅10人应答。

**判别与边界：** 设计权重均10；B的严重非响应不能靠原设计权重自动消除。

## K17.02.02 / K17.02.02.RQ01

**方法：** 随机分配与实际接受分开；以分配效应为预设目标时保留原组。

**合成输入：** A分配50人实际40人参与，B分配50人其中10人跨组；所有人均有结果。

**判别与边界：** 按原分配分析对应分配效应；按实际接受重新分组不继承随机可交换性。

## K17.02.03 / K17.02.03.RQ01

**方法：** 准实验比较须绑定识别假设；平行趋势是反事实假设而非前测相同。

**合成输入：** 处理组前60后75，对照前65后70；只一个前测，分组非随机。

**判别与边界：** 差中差=10分；平行趋势未证，因果解释HOLD。

## K17.02.04 / K17.02.04.RQ01

**方法：** 纵向测量记录同人身份、时间、缺失和依赖结构。

**合成输入：** 100人初测、仅60人复测，完成者初测比退出者高10分。

**判别与边界：** 完整案例变化不代表原100人；保留脱落与敏感性分析，不能用两次组均值替代配对变化。

## K17.02.05 / K17.02.05.RQ01

**方法：** 用同一目标人群的潜在结果差定义效应；观测组间差可能由共同原因产生。

**合成输入：** 高先备者自选练习，平均80；低先备者未选，平均60。

**判别与边界：** 20分是观测差；无可交换性证据不声称干预效果20。

## K17.02.06 / K17.02.06.RQ01

**方法：** p值针对零假设下预定统计量及模型；不解释为假设真概率。

**合成输入：** 双侧检验p=.03，效果0.1分，区间很窄，结果经20个探索性比较选出。

**判别与边界：** 未校正选择及多重性不支持预注册检验；p=.03并非零假设概率3%。

## K17.03.01 / K17.03.01.RQ01

**方法：** 抽样单位和分配单位各自明确，聚类设计不能把全部学生当独立随机分配。

**合成输入：** 10所学校各100人，随机分5校对5校；无随机抽取学校。

**判别与边界：** 分配单位学校；分析需考虑校内依赖；不能直接推断全国学生。

## K17.03.02 / K17.03.02.RQ01

**方法：** 按事前因果图检查共同原因、碰撞变量及中介；目标为总效应时不自动控制中介。

**合成输入：** 图C→T,C→Y,T→M→Y,T→S←Y。

**判别与边界：** 调整C为该图候选；调整S可能打开碰撞路径，控制M改变估计目标。仍需测量和图假设。

## K17.03.03 / K17.03.03.RQ01

**方法：** 结果缺失和选择机制显式建模；共同结果的条件化可能引入关联。

**合成输入：** 随机分配后仅分析自愿完成者；完成概率依处理与潜在表现。

**判别与边界：** 完成者对比不自动保持随机性；原分配组及缺失机制保留。

## K17.03.04 / K17.03.04.RQ01

**方法：** 效应修饰比较条件效应；中介关注经路径传递的效应，不能互换。

**合成输入：** 低先备组处理差2，高先备组差8；处理后学习时长改变。

**判别与边界：** 加法尺度效应差6；时长是可能中介而非已识别机制；分组差也需置信区间及设计。

## K17.03.05 / K17.03.05.RQ01

**方法：** 定义ATE、处理版本、一致性、可交换性和正值性。

**合成输入：** 两个等权层潜在均值差2与6；其中一层无对照实际观测。

**判别与边界：** 若潜在均值已知合成ATE=4；真实观察缺对照时识别条件不成立，不填4。

## K17.04.01 / K17.04.01.RQ01

**方法：** 结构化观察以行为事件和时点为单位，记录观察者和许可。

**合成输入：** 记录5分钟未发言，但书面解释正确；观察表仅记录举手。

**判别与边界：** 可记录未发言，不推断未参与或无理解；需其他独立证据。

## K17.04.02 / K17.04.02.RQ01

**方法：** 访谈区分受访者自述、研究者编码与事实核查；拒绝或无答不补值。

**合成输入：** 受访者说喜欢背词，但日志无练习；另一人拒答。

**判别与边界：** 第一条为自述与日志不一致的待查现象；第二条UNKNOWN，不能填低动机。

## K17.04.03 / K17.04.03.RQ01

**方法：** 编码本含单位、正例反例、双人独立编码及分歧裁决。

**合成输入：** 20段访谈18段双人一致，另2段分类冲突。

**判别与边界：** 一致率18/20=.9，不能证明类别含义有效；保留分歧及原编码版本。

## K17.04.04 / K17.04.04.RQ01

**方法：** 案例研究锁定案例边界、时间线、替代解释和证据来源。

**合成输入：** 单一班采用新教法后成绩上升，同时换教师及题库。

**判别与边界：** 可描述过程，无法隔离教法因果；不可推广为所有班的平均效应。

## K17.04.05 / K17.04.05.RQ01

**方法：** 互证以数据来源与误差机制独立性区分，不按报告数量累计。

**合成输入：** 三报告引用同一班日志，另有独立盲评新题。

**判别与边界：** 前三个同源一组；新题盲评不同观测机制，仍须匹配构念；不自动得因果。

## K17.05.01 / K17.05.01.RQ01

**方法：** 综述登记问题、检索时间/范围、纳入条件、去重、偏倚和综合规则。

**合成输入：** 同一研究有预印本及期刊版；缺少未公开结果。

**判别与边界：** 同一研究合并身份不重复计样本；检索不完整须保留限制，不宣称无发表偏倚。

## K17.05.02 / K17.05.02.RQ01

**方法：** 同效应量尺度与独立估计下的逆方差权重；共同效应解释需条件。

**合成输入：** 独立研究效应2、6，SE分别1、2。

**判别与边界：** 权重1、1/4；合成14/5=2.8；不得混合不同单位或重叠样本直接加权。

## K17.05.03 / K17.05.03.RQ01

**方法：** 随机效应权重包含给定研究间方差；均值不确定性与研究间分布宽度不同。

**合成输入：** 效应2、6，SE1、2，给定tau²=3。

**判别与边界：** 权重1/4、1/7；均值38/11；tau²是给定非估计，不能据两个点可靠拟合或外推预测区间。

## K17.05.04 / K17.05.04.RQ01

**方法：** 漏斗不对称需考虑选择报告、规模效应、异质性及分析误差。

**合成输入：** 较小研究普遍效果更大，但小研究都用更强辅导。

**判别与边界：** 存在设计差异竞争解释；不能只据漏斗图证明发表偏倚。

## K17.05.05 / K17.05.05.RQ01

**方法：** 证据体按具体结果、人群和问题分项审查偏倚、直接性、一致性、精度及缺失证据。

**合成输入：** 随机试验均报告短期词识别，目标是半年独立写作。

**判别与边界：** 短期词识别证据直接性不足；随机设计不能补偿构念和时间差。GRADE正式等级待框架源及判断。

## K17.06.01 / K17.06.01.RQ01

**方法：** 计算复现与独立新样本复制分开；本项目以精确输入、算法和环境记录计算复现。

**合成输入：** A原数据原代码重新输出同统计；B独立招募并执行同问题；C仅重新运行他人结果文件。

**判别与边界：** A计算复现；B复制研究候选；C不构成独立数据或重新计算。

## K17.06.02 / K17.06.02.RQ01

**方法：** 开放材料的版本、许可、依赖、随机种子与原始输入分别登记。

**合成输入：** 代码公开但数据限访问；仅有截图结果，无版本和输入。

**判别与边界：** 可记录代码可访问，不宣称可复现或允许再分发数据。

## K17.06.03 / K17.06.03.RQ01

**方法：** 目标总体及效应修饰变量匹配后再评估外推。

**合成输入：** 成年自愿者试验有效，目标为儿童必修课且资源不同。

**判别与边界：** 直接性未知；成人平均结果不自动用于儿童，需新适用证据。

## K17.06.04 / K17.06.04.RQ01

**方法：** 分配效应与实际处理效应分离；实际剂量和实施版本需观测。

**合成输入：** A分配10次活动实际6次，B分配无活动但校外2次。

**判别与边界：** ITT按分配对比，剂量分析另设识别；不能把60%剂量当60%因果收益。

## K17.06.05 / K17.06.05.RQ01

**方法：** 报告限制必须指出影响的推断和方向是否可确定。

**合成输入：** 一组脱落20%，另一组5%，缺失与结果关系未知。

**判别与边界：** 选择偏倚风险，方向UNKNOWN；不凭样本量或统计显著性消除，报告敏感性。
