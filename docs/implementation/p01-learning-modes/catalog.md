# P01 — 学习模式结构化模板

本阶段交付六种可选择的学习模式模板：引导式概念练习、提取与间隔复习、刻意技能练习、自我调节学习、协作对话学习、综合项目与迁移练习。它们是声明式模板，不是自动诊断器，也不是学习效果证明。

## 模式、活动与流程的边界

- Mode 是学习者可选择的会话组织方式；每个模式必须有目标、适用条件、活动、角色和切换边界。
- Activity 是有预算、观察要求和停止条件的单个活动单元。
- FlowSpec 是有界流程模板，显式定义入口、步骤、条件转移、终态、事件预算、未知处理和停止处理。
- Goal 与 SkillType 只描述当前任务范围，不代表稳定能力或个人特质。
- ObservationSpec 将辅助表现、独立表现、自我报告和迁移任务分开；缺失值保持 UNKNOWN，不补零。
- mode-flow-bindings.json 是显式绑定表。当前 canonical Mode 合同没有 FlowSpec 引用字段，因此不伪造 Relation 类型或隐式传递边。

## 共同约束

1. 学习者必须明确选择模式；未选择、撤回、未知或无权限时 HOLD。
2. 目标、材料、辅助程度、证据和预算必须在当前任务范围内明确。
3. 辅助表现不等于独立表现；自我报告不等于客观表现；一次新任务不等于普遍迁移。
4. 暂停保留检查点和剩余预算；恢复必须由学习者明确发起，并保持同一模式、同一检查点和幂等事件身份。
5. STOP 不自动恢复；HOLD 需要澄清或人工处理；FAILED 不自动重试。
6. 复习间隔、反馈、掌握门槛和练习次数是可配置条件，不是对所有学习者都有效的固定处方。
7. 文化、语言和群体上下文仅可由学习者选择或明确提供；不得根据身份、族群或个人背景自动分配模式。
8. 不生成诊断、能力分数、人格标签、临床结论或因果学习效果结论。

## 六种模式

- GUIDED_CONCEPT_PRACTICE：目标确认、示范、引导练习、独立检查与反思。
- RETRIEVAL_SPACED_REVIEW：无提示提取、区分辅助与独立响应、反馈及可调整的后续复习安排。
- DELIBERATE_SKILL_PRACTICE：限定子技能、短任务、过程反馈、预算内重试和独立检查。
- SELF_REGULATED_STUDY：学习者设定目标、选择策略、监控过程并反思；自我报告不作为能力测量。
- COLLABORATIVE_DIALOGIC_STUDY：自愿参与的同伴解释、对话与个人退出检查；文化/语言上下文由学习者选择。
- INTEGRATED_PROJECT_TRANSFER：整合多个活动，在明确的新任务中观察表现；不从单一任务推断一般迁移。

详细字段以 mode-design.json 和 canonical JSONL 为准。coverage.json 对 K05–K08、K13 的全部121个 D3主题逐项记录适用性、候选命题、来源允许列表、四个视角案例及组合边界。
