# V00 — finite text/import/flow prototype
An original synthetic two-step acyclic flow, derived from the DB02 mapping witness, is built as authoritative UTF-8 candidate records and imported via the exact DB02 importer in temporary directories. The prototype reads the FlowSpec, Activity and exact typed cross-package ConditionSpec from the selected SQLite memory tables. It never executes a learner action or writes knowledge. Twelve separate authored expectations cover completion, partial events, false, missing and wrong-typed conditions, explicit stop, unknown event, exhausted event budget, terminal immutability and numeric threshold. The prototype deliberately supports only the shown acyclic fixture, ALL and boolean EQ/numeric GE; other policy semantics are not implemented. This is NOT a generic runtime, real learning effectiveness test, independent oracle, G03/G04/G05, V01/V02 or CQ/LC qualification.

Reproduce from repo root: `python3 -m tools.knowledge_import.v00_prototype`; output must match results.json byte for byte. All artifacts are text; SQLite is memory only.
