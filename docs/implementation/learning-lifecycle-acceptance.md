## 有限验证案例需求（原创）
| ID | 正向及预期 | 负例及拒绝条件 |
|---|---|---|
| LC01 | HSK购物目标→词义、听说技能、独立交际任务及量规 | 仅覆盖词表不能证明交际能力；考试等级不等于掌握 |
| LC02 | 买/卖对比、词汇单元、组合情境任务分别调度 | 不因教材/组合重复创建词汇；组成不自动推出先修 |
| LC03 | 听辨任务匹配合法语音材料及适当替代 | 纯文字选项不能作为等价声调听辨证据；缺资源明确降级/停止 |
| LC04 | 引导对话记录角色、提示与独立产出 | AI生成答案不当作学习者表现；提示正确不能当独立正确 |
| LC05 | 同一观察产生可追溯估计，保留自述与缺失 | 单次答错不能确定注意力、动机或知识状态；UNKNOWN有效 |
| LC06 | 声调与词义混淆分别诊断、反馈、补救、变式复测 | 只观察一个错误不得确定原因；预算结束不无限循环 |
| LC07 | 无音频设备时调整任务/声明不适用；角色权限符合契约 | 无权限操作或需要监督的真实职业任务必须拒绝；知识模板不自授权 |
| LC08 | 新购物情境的延迟独立测试，有明确评价目标 | 即时准确、原题重复和模拟通过不能直接证明远迁移/真实能力 |
| LC09 | 允许选择活动、真实进步反馈、暂停及下一会话继续 | 强制连续打卡、虚构成就、忽略退出或重复事件不能通过 |
| LC10 | 固定流程版本与评价协议，生成候选修订并独立审核 | 使用时长改善不能单独晋升；候选写入正式库应拒绝 |
| LC11 | 复用辨别/反馈模板到汉语和另一个最小学科示范 | 不加载无关学科；不能因通用模板共享而伪造学科等价 |
| LC12 | 精确包版本依赖、稳定引用和历史会话复现 | 缺失/不兼容版本、孤儿引用拒绝；升级不篡改历史 |
LC11第二学科可用原创且专业可核证的小切片，不要求全量英语/数学导入。LC01–LC12均需实际可观察输出和独立预期，正负例、错误语义与证据写回。合成输入只证明结构/执行合同；任何教育效益需额外实证。不得因完成文档或数量统计宣布PASS。
