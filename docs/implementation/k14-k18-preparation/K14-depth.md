# K14 — 原创方法及有限合成案例

## K14.01.01 / K14.01.01.RQ01

**方法：** 语言学习经历与目标语言使用证据分开，按实际活动而非母语标签定位。

**输入：** 甲能独立读中文通知但口头问路不熟，乙口语流利但不识同一通知。

**判别与边界：** 读与说分别观测；不由一语/二语标签、接触年限断定统一水平。

## K14.01.02 / K14.01.02.RQ01

**方法：** 记录输入理解、产出尝试、互动修复和反馈时点。

**输入：** 学习者听懂路线后复述错误，伙伴澄清后正确；次日无提示新路线尚未测。

**判别与边界：** 本次输入与互动修复有证据，独立产出及保持未确立。

## K14.01.03 / K14.01.03.RQ01

**方法：** 迁移假设须与词义、输入、任务及一般错误区分。

**输入：** 学习者两次用相同母语结构表达中文，另一不共享母语者同样错误。

**判别与边界：** 母语迁移是候选解释，比较替代机制；不因背景标签自动归因。

## K14.01.04 / K14.01.04.RQ01

**方法：** 习得顺序观察绑定样本、目标结构、评量和时间。

**输入：** 研究样本A先正确使用结构X再Y，个体B未用X但独立Y达标。

**判别与边界：** 不能把研究平均顺序转为硬先修；验证X能力实际存在与否后才评价必要性。

## K14.01.05 / K14.01.05.RQ01

**方法：** 识字、解码、理解和表达各自设计观测。

**输入：** 学习者朗读通知准确但回答地点错误；另人不读出声但正确回答。

**判别与边界：** 朗读与阅读理解证据不同，书写能力仍未知；不得用单项代理全部。

## K14.02.01 / K14.02.01.RQ01

**方法：** 数感测试大小、表征与估算，速度不作为唯一判据。

**输入：** 估计39×21约800，实际819；另人快速写819但不能判断约800是否合理。

**判别与边界：** 前者有估算/量级证据；后者程序结果正确不自动建立数感。

## K14.02.02 / K14.02.02.RQ01

**方法：** 数学熟练度区分概念、程序、策略、推理及积极倾向，证据可相互补充。

**输入：** 甲算3/4+1/4=1但不能说明共同单位，乙能用图解释但计算慢；丙选择合适方法并给验证。

**判别与边界：** 分别记录各维度证据，态度需本人/观测合同，不由速度或一次正确推断整体熟练。

## K14.02.03 / K14.02.03.RQ01

**方法：** 命题的量词、前提、推理和反例必须同范围。

**输入：** 声称所有整数n使n²+n为奇数，n=2给6；另命题所有奇数平方为奇数。

**判别与边界：** 前一命题被合法反例推翻；后者需独立证明，不能复用不匹配反例。

## K14.02.04 / K14.02.04.RQ01

**方法：** 问题表征、策略选择、执行和检验分开。

**输入：** 长方形长5宽3，围栏预算要求周长；学生选面积15；另一学生选周长但算17。

**判别与边界：** 前者策略不匹配，后者执行错误；无过程记录不归因。

## K14.02.05 / K14.02.05.RQ01

**方法：** 误概念是跨题稳定模式假设；单次错误不充分。

**输入：** 2/3+1/3写3/6，另一等分题正确；新题与解释未测。

**判别与边界：** 可请求更多同结构题及解释，不以单错断言分母规则误概念。

## K14.03.01 / K14.03.01.RQ01

**方法：** 科学探究任务区分可检验问题、调查设计、观测及解释。

**输入：** 比较光照对种子萌发；两组同时改变光照和温度。

**判别与边界：** 问题可检验，但设计不能隔离光照；需控制温度或定义联合条件。

## K14.03.02 / K14.03.02.RQ01

**方法：** 论证明确主张、数据、理由及竞争解释。

**输入：** 三次相同条件植物生长记录支持趋势，另一组土壤不同。

**判别与边界：** 证据支持所观测趋势；土壤差异限制因果，允许质疑并修订。

## K14.03.03 / K14.03.03.RQ01

**方法：** 模型写出假设、预测、适用范围及检验。

**输入：** 恒速模型距离=速度×时间，速度2m/s、5s预测10m，实际8m且速度变化。

**判别与边界：** 检查恒速条件和误差，修订模型而非将模型等同实物。

## K14.03.04 / K14.03.04.RQ01

**方法：** 实验评价分别核对计划、操作、读数、重复、误差与安全。

**输入：** 三次长度读数10.1、10.2、10.1cm，标尺零点偏差未知。

**判别与边界：** 记录平均及离散，系统误差未知；不能称精确真值或绕过安全步骤。

## K14.04.01 / K14.04.01.RQ01

**方法：** 工作中学习区分岗位暴露、训练、观察和个人实际表现。

**输入：** 值班十次只观看维修，独立安全模拟成功一次。

**判别与边界：** 分别登记观察及模拟证据；工时不等于实际维修能力。

## K14.04.02 / K14.04.02.RQ01

**方法：** 操作技能验收绑定工具版本、容差、安全权限及异常处理。

**输入：** 标准要求误差≤0.2mm且完成安全检查，测得0.1mm但检查缺失。

**判别与边界：** 尺寸条件达标、整体证据不足；不得认证安全操作。

## K14.04.03 / K14.04.03.RQ01

**方法：** 迁移任务明确源环境与目标环境的变化、权限及支持。

**输入：** 训练在模拟器完成故障排查，真实设备接口与警报不同。

**判别与边界：** 模拟证据有效限原条件；真实操作需合适授权和独立目标任务，不自动迁移。

## K14.04.04 / K14.04.04.RQ01

**方法：** 职业资格与系统学习证据分离，核对适用标准和授权机构。

**输入：** 学习系统显示所有模拟任务达标，尚无正式机构评价。

**判别与边界：** 仅输出任务表现证据；资格状态UNKNOWN，不发放认证。

## K14.05.01 / K14.05.01.RQ01

**方法：** 跨学科共享实践只复用抽象结构，保留专业验证规则。

**输入：** 数学普遍命题以演绎证明；实验规律以观察和模型支持。

**判别与边界：** 都可检查主张证据，但重复测量不证明数学全称命题，演绎不替代实测。

## K14.05.02 / K14.05.02.RQ01

**方法：** 情境知识需辨认适用条件、共享结构及不适用边界。

**输入：** 同样比例表用于配方和非线性收费，后者有固定起步费。

**判别与边界：** 配方可用正比模型；收费一般不满足正比，不由表面相似选同算法。

## K14.05.03 / K14.05.03.RQ01

**方法：** 真实任务保存角色、协作贡献、权限与工具条件。

**输入：** 团队完成报告，甲采数据、乙分析、丙写作；报告正确。

**判别与边界：** 分别记录贡献，不给每人全部能力结论；需要独立观察。

## K14.05.04 / K14.05.04.RQ01

**方法：** 转移检验声明源与目标任务、时间、表面/结构变化和提示。

**输入：** 练习方形面积后独立求新长方形面积正确；复合图形分解未测。

**判别与边界：** 记录该目标近迁移候选，不外推复合任务或远迁移。
