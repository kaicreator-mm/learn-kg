# K18 — 原创方法及有限合成案例

## K18.01.01 / K18.01.01.RQ01

**方法：** 儿童学习观测记录任务和环境，年龄不是固定能力门槛。

**输入：** 同龄两人一人独立拼读、一人仅借提示拼读。

**判别与边界：** 记录两种表现及支持，按能力任务调整，不自动根据年龄分组定级。

## K18.01.02 / K18.01.02.RQ01

**方法：** 青少年发展研究的群体结果与个人实际选择分开。

**输入：** 两名同龄学习者一人认可长期目标另一人拒绝该活动。

**判别与边界：** 按本人确认目标与选择，不从年龄推断动机或冲动。

## K18.01.03 / K18.01.03.RQ01

**方法：** 成人学习用既有经验、实际机会和目标约束设计。

**输入：** 成人工时8小时仅余20分钟，已有操作经验但理论概念未知。

**判别与边界：** 提供可选20分钟任务，理论另测，不由成人身份推断掌握。

## K18.01.04 / K18.01.04.RQ01

**方法：** 老年学习按实际感觉/任务需求和个体证据适配。

**输入：** 两人同龄，一人选择放大文字且正确阅读，另一无需辅助。

**判别与边界：** 分别保留可及性条件；不把年龄或放大文字当认知缺损。

## K18.01.05 / K18.01.05.RQ01

**方法：** 发展轨迹需同人、可比较时点与量尺，横断平均不可替代。

**输入：** 组A今年60分、组B明年70分，人员不同；个体C同量规60→65。

**判别与边界：** 前两组不可解释同人变化；C观察差5，需条件核对及误差，非必然趋势。

## K18.02.01 / K18.02.01.RQ01

**方法：** 区分神经信号、行为、教学干预及因果证据层级。

**输入：** 扫描研究观察脑信号与任务正确率相关，无随机教学干预。

**判别与边界：** 只能记录关联，不能决定某教学有因果效益或诊断个人。

## K18.02.02 / K18.02.02.RQ01

**方法：** 神经可塑性证据标明物种、任务、层次及时间。

**输入：** 动物环境实验发现神经变化，人类课堂无同类干预和行为数据。

**判别与边界：** 动物结果是机制研究线索，不能作为课堂效果或个人预测。

## K18.02.03 / K18.02.03.RQ01

**方法：** 敏感期主张需明确能力、经验时段及结果，区分相对优势和绝对不可能。

**输入：** 研究样本早学某音位平均更好，晚学者中仍有独立达标者。

**判别与边界：** 不得将平均差写成年龄禁区；具体个体按实际表现和目标评量。

## K18.02.04 / K18.02.04.RQ01

**方法：** 跨层桥接为可检验假设链，每层分别列证据。

**输入：** 动物神经变化→成人反应时变化→学生长期理解；只有第一层数据。

**判别与边界：** 后两层HOLD；不能把第一层支持传递为教育干预结论。

## K18.03.01 / K18.03.01.RQ01

**方法：** 记录自愿提供的休息情境与同条件表现，不诊断睡眠问题。

**输入：** 某日自述睡眠不足且测验5/10，另一日8/10但题目不同。

**判别与边界：** 差异可能由多因素，无法归因睡眠；可提供自选休息/改期，不作医疗建议。

## K18.03.02 / K18.03.02.RQ01

**方法：** 疲劳记录为本人自述或观测情境，时间/错误非特异。

**输入：** 学习者自述累并希望暂停，另人任务耗时长但未自述。

**判别与边界：** 尊重暂停；第二人状态UNKNOWN，不由耗时诊断疲劳。

## K18.03.03 / K18.03.03.RQ01

**方法：** 压力与表现分开记录，比较需明确任务、时点、来源及替代解释。

**输入：** 高压考试低分，练习场景高分且题型不同。

**判别与边界：** 不能隔离压力效应或推断疾病；先核任务与本人需求。

## K18.03.04 / K18.03.04.RQ01

**方法：** 健康相关数据最小化，学习系统记录功能需求和许可。

**输入：** 本人仅请求大字显示，不愿披露疾病。

**判别与边界：** 提供可选大字，不要求诊断详情；未授权不存储敏感推断。

## K18.04.01 / K18.04.01.RQ01

**方法：** 语言发展证据依经验、任务和交互环境，不以年龄或接触时长替代。

**输入：** 一人能听懂指令却不能书写，另一人相反。

**判别与边界：** 分别记录语言活动构念，不依据年龄标签合成总体能力。

## K18.04.02 / K18.04.02.RQ01

**方法：** 执行功能任务可能混合抑制、更新、转换、速度和语言要求。

**输入：** 任务A切换规则慢但准确，任务B语言说明误解。

**判别与边界：** 区分时间/准确与理解条件，不由单项错误诊断执行功能。

## K18.04.03 / K18.04.03.RQ01

**方法：** 文化、环境及发展变量作为具体条件，不作身份决定论。

**输入：** 同一社区两人资源和活动不同，相同年龄表现不同。

**判别与边界：** 以实际机会/经验解释候选；不以群体标签填入生物或能力属性。

## K18.05.01 / K18.05.01.RQ01

**方法：** 教育应用需明确从机制到行为及学习效果的证据链。

**输入：** 训练后脑激活变化，独立保持测验未改善。

**判别与边界：** 记录神经结果与行为结果分离；不声称学习效果已证。

## K18.05.02 / K18.05.02.RQ01

**方法：** 核验神经迷思时追踪主张、证据层级及推理跨越。

**输入：** 广告称脑区激活证明某课程使所有人提高智力，只有一次小样本相关。

**判别与边界：** 缺因果、适用人群和构念证据，HOLD；脑区术语不是效果证明。

## K18.05.03 / K18.05.03.RQ01

**方法：** 自愿功能支持与疾病判断分离，保留拒绝和撤销选择。

**输入：** 本人希望降低界面刺激但不愿讨论原因。

**判别与边界：** 提供可撤支持选项，记录授权范围；不推断疾病或要求敏感信息。
