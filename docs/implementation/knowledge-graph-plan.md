G01 并行校准 HSK 范围、官方版本、权利及案例需求；G02 每个通用模块尽可能提供适用的 HSK 实例，不强制不适用领域；G03 检查跨域绑定和泛化边界；G04 设计独立 ID、版本映射与学习证据连接；G05 用可核验的初级 HSK 切片验证知识→任务→观察→状态→决策→评价链。具体规模和等级待 G01 来源校准，不要求首版全量词表。
