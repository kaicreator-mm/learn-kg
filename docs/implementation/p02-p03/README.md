# P02 目标协商、学习准备与 P03 学习活动单元（受限候选）

P02：目标协商→匹配的现状/先备观察→资源和全部时间成本核查→本人选择计划。缺失现状保留 UNKNOWN；请求补测或预算不足时暂停；不能用先备知识假设阻断必经路径。四个步骤是候选模板，不是实际学习状态。

P03：讲解、示范、辨别、回忆、模仿、解释、产出、问题解决、反思九类活动。各活动有独立目标、对象、角色、观察单位、条件及预算。教师呈现仅为实施证据；模仿是辅助证据；反思自述不能替代客观表现。其他表现也只形成任务观察，不授予掌握或迁移资格。资源、目标、评分版本及提示条件必须核对。

## 可读与结构化材料

design.json 为可读的 UTF-8 设计；activity-bindings.json 明确 Activity 与 ConditionSpec、输出证据类型；input-bindings.json 绑定当前上游非经验方法及项目规则。canonical JSONL 通过 learning-process.manifest.json 直接导入内存 SQLite；不交付持久数据库。

P02 四个 S01 需求分别对应 P02.GOAL、BASELINE、RESOURCE、PLAN；P03.RQ01 对应九类目录，RQ02 对应每个目标/对象引用，RQ03 对应观察单位和角色，RQ04 对应版本、支持与资源守卫。适用性仍待独立复核；真实评分、资源实例、学科知识绑定、跨活动组合和恢复执行由后继 P04/F/A 处理，不把结构或测试计数当作完备性。
