# HSK 首个学科实例域（D007，DRAFT）

## 边界
通用学习科学 K01–K17 与 SUBJECT.HSK 具体汉语知识在同一 monorepo 维护，独立标识与来源。K14 研究语言学习机制，SUBJECT.HSK 记录汉语实际内容和能力要求。HSK 是标准化考试目标，不等于完整汉语能力；不使用真实学习者隐私数据。未来支持 JLPT 等并列学科域；本轮不修改 xLearn。

## 版本
分别建模 GF0025-2021 能力规范、HSK 2.0 历史考试体系和 HSK 3.0 新考试体系；官方公告称 2026-12-13 全球正式开考，截至 2026-11-26 尚未到该日期。标准、大纲、试行、正式实施分开标记。等级关联附规范版本、准确条目位置、来源和生效范围；不存在默认等价。优先研究新体系，旧版兼容不等于逐项已经映射。S005–S009 为官方发现入口；逐原文核验与权利审查未完成。

## 组合案例需求（原创、未核验、未执行）
- H-P01（K02/K05/K10/K11）：词汇“买/卖”，分别测试听辨、字形辨认、词义回忆和情境产出；正确选择不等于会说会写；按独立观测状态安排候选复习。
- H-P02（K03/K04/K06/K12）：语法“了”的不同构式，按情境与条件生成正反例，区分句末和动词后用法；不可从一个例句推出所有规则；语法断言待专业核证。
- H-P03（K07/K09/K10）：同一词汇在有提示和无提示任务中表现不同，分别记录任务、观测、提示与评分，不把考试等级等同个体掌握。
- H-P04（K08/K13/K16/K17）：不同母语背景学习者声调错误，提出备选解释、控制变量及复测；不得仅凭母语标签确定原因。
- H-P05（K04/K09/K11/K17）：比较词表记忆与真实语境使用；设计延迟、迁移、控制条件与独立预期。

## 初版贯通目标
