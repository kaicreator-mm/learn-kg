# 主责与知识组合
## 17→19 域候选修订（非冻结）
K01 保持理论和解释框架，具体发展与神经生理内容路由 K18；K02 负责认知加工机制，K18负责生命周期、生理及神经证据层。K16 原“个体差异、可及性与伦理”拆分：个体差异、功能需求、无障碍留 K16；公平治理、数据隐私、伦理风险、监督转 K19。测量公平与 DIF 的测量专业定义仍归 K09；K19引用其结果作治理决策。K08 个体动机；K13 社会环境；K18 发展规律，不重复。
K01–K17 其余 ID 原样保留；K14 只拥有学科特有学习机制，不拥有字词句等学科实体。K05 负责方法的一般实证与设计原则，K11 负责给定目标与状态下策略选择；K10 负责估计潜变量，K09 负责观测和分数的测量解释。K03 负责知识结构语义，K07 负责课程顺序与目标，K12 负责具体学习资源与题目设计；K06负责教学干预机制及实施，K15负责技术支持系统及交互。K17负责证据方法，具体研究结论由对应域拥有。
H01–H07 保持既有ID，H03明确构词及义项，H04明确语法与构式，H05明确语用语篇。H06 技能构念与任务表现；H07 标准版本和成员关系；实际字词句不按等级复制。
 
## 类型分离
概念、定义、理论、经验命题、数学模型、算法、教学政策、规范要求、领域实体、技能、目标、任务、观测、学习者状态、决策、评价必须分开。知识分类边不等于知识逻辑边；学科实体与其教学顺序、前置、难度、熟练度和规范等级不同。不能将相关变成因果、共现变成先修、题目答对变成掌握。

## 组合顺序不是因果模型
A01–08 是查询和应用需求，依赖关系在 G04 形式化。领域知识必须跨案例可复用，不在每个应用重复主张。所有跨域关联需方向、条件、类型、证据；无条件关系不得从学科分类树自动生成。
