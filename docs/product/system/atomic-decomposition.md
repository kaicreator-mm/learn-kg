# D4 原子分解合同与初始示范
D3 为主题；D4 必须是可独立定义、检验、反驳或限定的一个知识命题需求。定义、公式、参数解释、前提、经验效应、模型与干预政策拆分。禁止把主题名称当作已证知识。先按全域主题建立库存，再按实际知识复杂度分解；不平均分配数量。
 
示例（原子需求候选，不是accepted claim；各主题尚需补齐D4）：
| ID | D3 定位 | 独立知识需求 | 验证/负边界 |
|---|---|---|---|
| QD4-01 | K02.06.04 | 再认与自由回忆的操作定义分离 | 同材料不同任务；不能以再认正确率代替自由回忆 |
| QD4-02 | K05.02.01 | 间隔效应定义与时间分配对照 | 总时长、延迟、材料、对照固定；不预设所有间隔更好 |
| QD4-03 | K05.02.03 | 扩展间隔方案是否优于固定间隔的条件 | 区分比较组及保持延迟；无证据不设最优 |
| QD4-04 | K03.06.04 | 必要先修关系的可识别证据 | 教材顺序非证明；比较替代路径 |
| QD4-05 | K09.04.01 | Rasch 成功概率模型及量尺假设 | 独立数值 oracle；不得当因果学习模型 |
| QD4-06 | K10.02.01 | BKT 观测更新的公式、条件 | 独立算例及极端参数；不直接解释多组件任务 |
| QD4-07 | K10.02.02 | 猜测与滑移参数的语义 | 区分观测与潜在掌握；不得由单次正确识别参数 |
| QD4-08 | K11.02.02 | 保持目标与复习时机的决策约束 | 给定模型和预算；不可从概率直接推真实收益 |
| QD4-09 | K17.03.02 | 混杂对干预效果估计的影响 | 对照因果图/设计；相关不等于因果 |
| QD4-10 | H01.03.01 | 普通话声调类别和语音实现的区分 | 定义及录音对照；变调语境不机械套用 |
| QD4-11 | H02.03.01 | 字形身份与多音读法关系 | 同字不同词语语境；字形不唯一决定读音 |
| QD4-12 | H03.01.04 | 词条与义项区别 | 同一词的不同义项；级别附着对象明确 |
| QD4-13 | H04.04.01 | 助词“了”构式与条件的分解 | 句中和句末对照；不能全解释为过去时 |
| QD4-14 | H06.02.03 | 口语准确性评分构念与任务证据 | 评分规则、发音和语法证据；不能用选词题代替 |
| QD4-15 | H07.03.03 | 版本化词汇条目成员关系 | 大纲精确条目；不把级别成员推成先修 |
 
每一D4正式入库时必须包含稳定ID、定义/命题、条件、范围、来源定位、反例、主责、关系及四视角案例（适用时）；数学内容需独立计算，实证主张需明确研究设计，规范需版本和条文。G01目标为可分解的覆盖地图，不强行在此轮写全D4；G02按完整模块深化。
