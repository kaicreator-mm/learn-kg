## 专业知识分解
- 两状态和无遗忘假设；G/S条件概率语义；贝叶斯后验；学习转移；表现预测；独立观测输入保护（项目工程策略，与原文分开）。
- p为观测前先验，G=未习得时答对概率，S=已习得时答错概率，T=本次有效机会后的学习转移率，均为[0,1]。
- P(C)=p(1-S)+(1-p)G；答对后验=p(1-S)/P(C)，答错后验=pS/[pS+(1-p)(1-G)]。下一先验=q+(1-q)T。分母为零拒绝。公式是依据条件概率与原模型假设的独立数学展开；不要把模型估计等同观察或教育效果。
- 使用合成p=2/5,G=1/5,S=1/10,T=1/10：答对后验3/4，下一先验31/40；答错后验1/13，下一先验11/65。参数仅为算例，不是推荐默认值或真实学习者数据。
