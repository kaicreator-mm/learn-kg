## 模型和决策
固定半衰期曲线 p=2^(-delta/h)，HLR估计 h=2^(theta·x)，逆求 h=-delta/log2(p) 仅在delta>0、0<p<1时有限正值。试点固定day为时间单位，拒绝错单位、零/负半衰期、负时距、溢出/下溢；无中途练习时才应用固定曲线。特征/权重拟合、原研究训练损失与个体校准尚未实现。合成权重非真实参数。原文预测实验报告MAE 0.128 vs 0.235（HLR/Leitner），AUC 0.538 vs 0.542；不把预测误差转成长期学习收益。

复习规则属于项目候选，不是论文最佳调度结论。依序：权限拒绝→非法/缺失输入→模型不适用→高于用户阈值则等待→预算不足延期→否则建议复习。阈值相等算到期，目标须严格0到1之间；成本/预算均为分钟。只输出建议，不执行活动。实际学习记录归下游。
