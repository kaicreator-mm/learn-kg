# 学习模式、诊断与反馈组合（草案）

每个模式必须明确目标构念、材料、先备条件、资源、支持程度、可访问路径、预计成本、终止规则、评价和适用边界。提取/间隔用于保持候选；交错/案例比较用于策略辨析候选；自解释/案例比较用于概念连接候选；指导练习与独立练习用于程序性任务候选。不是排他映射或最优调度。只有范围匹配且授权、预算、可及性、先备条件明确时才列入候选；不自动执行。

错误诊断：任务响应、评分量规、辅助、环境、对照任务分离。未作答/中断→缺失；单个错误→辨别性任务；独立对照和重复模式→可检验假设；正确→仅无观察到错误。反馈随证据类型选择，量规争议先复核，支持可拒绝。鼓励、进展反思及自选小目标都可拒绝；无经核进展时不声称进步；不可因学习次数、连续签到或群体统计强制行为。

例：中文认读错字可能源于形似、音近、义项歧义或任务条件，须用分别控制的对照任务；数学策略错误需区分计算失误和表征/概念问题；职业操作须区分模拟、实际工具与权限。上述跨学科例子是设计，并非验证实际学科效果。P08–P11函数只验证有限路由，不验证任务内容、输入真实性、反馈质量或长期学习成效。
