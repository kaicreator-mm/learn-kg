## 关键专业边界
- 区分感知输入、注意选择、报告和推断；d′敏感度与c判准分开，不能用命中率或漏报诊断个人。记录正确/错误及速度权衡。
- Baddeley多成分、Cowan状态观点和槽位/资源模型为竞争解释；不把固定项目数当个体容量，不把模型组件当物理脑结构。言语与视觉空间保持任务有条件区别。
- 区分情景、语义、程序记忆及直接/间接测量，K01拥有理论分类，K02专注具体操作边界；K03知识结构，K04技能/迁移，K05策略，K09测量，K10概率建模、K18神经机制保持主责。
- 区分编码线索、检索线索、竞争与保持时距；再认、线索回忆及自由回忆保留QD4-01引用。Ebbinghaus复现为单人节省法，节省量不是回忆概率，不将其作为通用遗忘模型；HLR/BKT不重复建设。
- 负荷类别是理论构念，内在复杂度依赖已有知识，专家反转需实际领域证据，不按身份撤销支架；不同测量指标不自动相加或决定负荷类型。
