## 专业边界
认知、知觉、动作与综合技能分别评价；程序化与自动化是理论解释，速度准确权衡及练习阶段需明确任务条件。Fitts Shannon形式仅快速指向任务，参数实际未拟合；运动适应误差递推为零偏置合成抽象，不是PLOS原文方程复现。反馈使用、变式练习及瓶颈需独立观察。迁移按Barnett/Ceci的内容及情境维度记录，不用总距离强行近远二分。正负迁移需可比对照，适切加工不等于表面相似。专家组块、模式识别、策略和适应性分开；子技能不替代协调、重组及真实任务。实际职业资格由有权主体评价，不由知识库生成。
