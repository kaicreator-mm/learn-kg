## 组合验证需求（原创情境）
1. **听辨与设备限制**：某任务要求独立听辨，设备无音频。K13/F07记录环境不适用；K16提供可及替代活动，但若改变构念，K09不得将阅读分数归入听辨结果；K10保持缺失或未知；K11/P08改选适用活动，非失败惩罚。验证预期是拒绝错误状态更新。
2. **跨学科任务**：相同的符号—意义映射策略可用于汉语和数学示例，但学科目标/构念/条件分别保留。K14审查特有机制，K03类型复用不制造跨学科先修，K04迁移需独立证据。最小第二学科夹具不等于完整学科知识包。
3. **生成式AI内容**：K15生成候选练习，K12核对答案和引用，K09核对测量构念，K19检验权利/授权；E01只登记候选改动，K17判断证据是否支持。未审内容不得进入正式包。
4. **效果与机制**：假设一项研究只报告短时表现或神经相关变化。K17检查设计、混杂、外推，K18记录证据层次；不得把结果晋升为长期学习或个体诊断。K08激励、K11决策若消费该结论须检查适用条件。
5. **学习数据授权**：有权限提供反馈不意味着有权训练模型或公开学习者信息。K19限制用途，P10退出和纠正，E01外部改进只接收授权证据与候选；无权限拒绝，不因数据齐全而放行。
