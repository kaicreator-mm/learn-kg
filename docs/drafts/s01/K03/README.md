## 专业内容及应用边界
事实、概念、关系、过程及条件知识是不同知识表达对象；严格定义与经验类别区别，原型/范例不必等于规则。组成、分类、顺序、必要前置、建议、因果、类比分开。必要前置按限定目标和允许替代路径审查，路径内ALL、路径间ANY，缺失保留UNKNOWN，空路径拒绝。模型可区分性与组件识别不等于真实因果或统计可识别。KLI的KC为从表现推断的认知单位，不等于D4文件记录。理解需事实、关系、解释与实际应用证据；误概念作为假设，概念重构需延迟与陌生任务。K01/K02保持理论和认知主责，K09测量、K10估计、K17因果、F06诊断、P04执行、E01版本治理不重复。
