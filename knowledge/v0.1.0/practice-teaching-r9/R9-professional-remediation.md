# R9 专业整改（覆盖同主题 R8 方法与叙述例；旧原始文件保留）

## K05.03.02 / RV01

**方法：** 组块练习有类别提示，混合新题同时要求策略选择和执行。分别记录目标规则、所选策略及实际执行；两类错误可以并存。

**合成输入：** 同难度新题要求计算长方形面积，长3宽4。甲选周长2(3+4)=14；乙选面积3×4但算成11；丙只交11，无步骤；丁选周长且算错成13。

**预期及边界：** 甲为选错策略、所选策略执行正确；乙为选对、执行错误；丁两类错误；丙的选择与执行均UNKNOWN。混合3/6总分本身不足以归因。

## K05.03.01 / RV01/RV02

**方法：** 交错安排混合类别并可能要求选择策略；类别内/间相似、目标和反馈是必要比较条件。

**合成输入：** 面积与周长各2题，AABB与ABAB匹配数量、反馈、总时长、材料、延迟；新题一组不提供公式，另一组提供公式名称。

**预期及边界：** 不提供公式且类别未标记的任务可观察自主策略选择；提供公式时仍可能观察计算或其他区分能力，但不能证明无辅助选择。只在匹配评量内比较。

## K05.02.01 / RV02

**方法：** 学习间隔与最后暴露到终测的保持间隔是不同变量；匹配次数、材料、单位与测试条件。

**合成输入：** A日0、7两次学习，日35测；B日0、14两次学习，日42测；两组同词项集合或平衡等价材料、每次20分钟、同学习操作/提示/反馈和独立测验量规，末次暴露后均28天。

**预期及边界：** 间隔7与14天、保持均28天；匹配条件成立才比较保持表现。若B每次40分钟或测验形式不同，则不能把差异唯一归于间隔。无成绩数据不宣告优胜。

## K05.02.04 / RV02

**方法：** 目标期限是调度输入，不是个人遗忘模型；必须满足日期、机会、成本与测量合同。

**合成输入：** 日10最后学习，目标日30独立回忆10词至少8词。可用窗12日10分钟、20日15分钟、26日10分钟；总预算20分钟。A=12+26各10分钟，B=12+20需25分钟，C=26单次10分钟。模型身份、参数、适用人群和校准证据均未提供。

**预期及边界：** A/C可行，B超预算拒绝；A与C的预测保持概率UNKNOWN，不排名效果。可按本人确认的次要规则（优先保留10分钟）选择C，标为预算选择；若已提供K10的模型版本、校准及适用范围，才调用对应预测，不能把8/10阈值当预测概率。

## K05.05.02 / RV02

**方法：** 笔记生成和复习是可分别操控的学习操作，联合效果不等于独立效应相加；另区分阅读笔记与无提示提取。

**合成输入：** 同课材料及总学习时长，四组：自行记笔记/不记×后续阅读匹配内容/不阅读；无笔记组的复习材料为统一讲义。另记录是否在复习时遮住材料自测，延迟独立测验。

**预期及边界：** 四组支持描述各组合差异，来源及复习内容差异需另控制；阅读笔记不等于提取，自行生成与材料存储不等于因果可加。未知复习行为时不认定联合操作完成。

## K05.05.04 / RV02

**方法：** 语言与非语言表征和感知通道不是同一划分。教学中的图文配合应检验表达关系一致性，而非按学生感官偏好分配。

**合成输入：** 同一可见文字说明水从高处流向低处；A流程图箭头高→低，B图示反向，C只换装饰色。另有口头说出相同关系。

**预期及边界：** A图文语义相容，B冲突需纠正，C颜色变化不能证明语义增益；可见文字与口头词句均为语言材料。仅凭偏好不能判断应采用何种教学匹配或效果。

## K07.02.02 / RV03

**方法：** 安排顺序、逻辑依赖和实证必要先修不同；顺序可为资源或教学效率服务。

**合成输入：** 声称A能力是B的必要条件。甲未上A课但实际A能力未知，独立B达标；乙已具A能力经C路径独立B达标；丙在同一允许范围独立观测确认A能力不存在且独立B达标；丁只有教师帮助下B达标。

**预期及边界：** 甲HOLD，乙不是反例；丙在该范围反驳排他必要性；丁独立证据不成立。仍可因教学成本推荐A→B，不由教材顺序证明必要。

## K07.01.02 / RV04

**方法：** 修订Bloom分类的知识维度与过程维度可交叉；任务可同时覆盖多个单元格。以观察对象和实际操作分类，而非仅凭动词。

**合成输入：** 四项数学任务：①回忆π符号名称；②解释面积和边长的关系；③对未标记面积/周长问题选择并执行适当程序，说明选择条件；④拆解复合图形识别各组成部分及其结构关系。另一个目标仅写‘分析公式’无产出要求。

**预期及边界：** ①事实知识×记忆；②概念知识×理解；③程序知识×应用（选择理由另可涉及理解/评价，按量规）；④概念知识×分析（执行计算另记应用）。无明确产出‘分析公式’为UNKNOWN。复合目标可多格，不要求全局固定阶梯。

## K07.03.04 / RV04

**方法：** 跨域依赖要绑定类型、版本和具体目标条件；相似名称不能代替专业关系。

**合成输入：** 合成对象 identity=(math,0.1,SkillType,ratio) 与 (chemistry,0.1,TaskSpec,concentration)；后者量规同时要求比例运算与g/L单位解释。学习者独立比例题达标但浓度题单位错；另有 math,0.2 的同名不同定义。

**预期及边界：** 只记录组件证据与整体缺口候选；不得由同名、比例达标或单例失败推出必要关系。0.2不是0.1，须重新核对。合成引用不是实际H/K正式知识身份。

## K08.01.01 / RV05

**方法：** 成功期望、任务价值及成本分别测量；活动选择还受可用机会与其他目标约束。

**合成输入：** 两人同样未参加练习。甲自述感兴趣、对职业有用且身份重要，但预计做不好；乙自述有信心且重视目标，客观仅10分钟、任务需30分钟；丙不提供自述。

**预期及边界：** 甲记录低成功期望的自述，乙记录客观时间不足；另询问感知努力、机会及情绪成本，不从客观分钟数直接填入主观成本。丙原因UNKNOWN，不按参与率诊断动机。仅经本人认可建议可行支持。

## K08.05.05 / RV05

**方法：** 目标冲突涉及多个价值、成本、优先级和资源；由学习者决定取舍。

**合成输入：** 语言练习与工作考试各需40分钟、实际可用60分钟；本人说语言有趣、工作考试更符合职业目标，但担心错过语言活动。另有学习者拒绝透露价值偏好。

**预期及边界：** 两完整任务不可同时排入；兴趣、效用、重要性、感知机会成本与客观20分钟缺口分开记录。仅列可选缩短/延期安排，需本人确定取舍；未知偏好不赋默认效用权重。

## K08.05.04 / RV05

**方法：** 努力调节可涉及注意、策略、环境与帮助调整；休息和停止是本人选择，时长不是努力质量。

**合成输入：** A专注20分钟独立正确；B坐60分钟含30分钟网络故障、20分钟休息、10分钟主动练习；无相同目标及任务难度信息。

**预期及边界：** 记录不同实际活动与外部障碍，不判B努力低；先询问是否需要离线资源、策略调整或休息。比较学习成果须匹配目标和测量。没有本人许可不改变计划。

## K08.06.03 / RV05

**方法：** 协作场景区分个体自我调节SRL、由特定成员引导的共同调节CoRL及群体共同协商形成的社会共享调节SSRL；可在同一活动中转换。

**合成输入：** 同一小组阅读任务：甲自行设个人时间表和核对答案，伙伴只在旁；乙发现同伴偏离目标，暂时引导其制定并执行检查表、之后交还责任；丙组三人共同讨论目标，协商分工、联合监控并共同修改计划；丁只观察到同时答题正确。

**预期及边界：** 甲为协作背景下个体SRL；乙为CoRL引导事件；丙为SSRL过程证据候选；丁调节形式UNKNOWN。不能从成绩、共同目标口号或共同在场推断共享调节及因果效果。

## K06.04.03 / RV07

**方法：** 无辅助发现与增强发现是不同干预；同一论文中的两个元分析比较组不同，效应量不能相减当直接比较。

**合成输入：** Alfieri等2011同一论文：元分析一无辅助发现相对显式教学；元分析二增强发现相对其他教学（对照可能含显式或无辅助发现）。精确效应量留原历史记录。

**预期及边界：** 不同对照集合不能直接构造增强相对无辅助的效果差。选择指导时另核任务、先备知识和目标；不声称所有发现教学有害。

## K06.07.04 / RV07

**方法：** 实施忠实度区分内容、频率、持续、覆盖与质量、参与响应；适应性改动须说明必要成分。

**合成输入：** 计划8次每次30分钟，实际6次30分钟；已完成指定核心活动，替换可选示例，但服务覆盖人数及实施质量未知，成绩上升。

**预期及边界：** 次数剂量6/8=.75，时间180/240=.75；核心内容需按版本核对，覆盖及质量仍UNKNOWN；不称完整忠实度，成绩提升不是忠实度本身。
