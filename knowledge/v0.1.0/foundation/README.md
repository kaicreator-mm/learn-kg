# K01–K04 正式专业候选（KR01 范围）
本批以 G01 已接受范围和 DB01/IF01 候选结构为输入。四个模块各自保存 coverage.json 与可读 JSONL 记录。两个 manifest 描述本批版本化逻辑包；这是候选编写交换形式，不是发布包，rights=HOLD。旧候选原文与源证据保持原样，新的结构化记录是确定性适配产物；新增专业原子和案例作者输入见 source-research.json、discrimination-cases.json、finite-oracles.json，不在适配输出中另行手改事实。

- K01 学习理论：19主题、共同预测误差、关联与习惯、意识与表征、情境和解释边界。
- K02 认知记忆：28主题、辨别与判准、切换与混合成本、检索线索、节省法及成本下限、认知负荷边界。
- K03 知识结构：26主题、语义关系、替代前置、概念规则、证据与概念改变、整合KC；SKOS近似映射不得自动传递。
- K04 技能迁移：24主题、独立与辅助表现、自动化、误差更新、迁移维度、后续学习速度与真实表现边界。

新增97主题区分性合成案例、4个源文定位新命题、8个旧命题来源位置复核、20个实际固定预期有限数值/逻辑检查；保留50个历史数值/逻辑设计与旧运行证据。四个ModelSpec为狭义有限公式，非真实参数校准。来源复核只核对列出的HTML段落；其余原定位未核实、缺失、多源归属、科学充分性与专业关系待定均保留。不得以本批新增案例覆盖每项需求的充分性。所有专业资格与CQ/LC仍NOT_RUN。KR01逐模块独立审查，不能整批自动晋升。

在仓库根执行 python3 knowledge/v0.1.0/foundation/run_oracles.py 与 build_modules.py；需要Python 3.12/jsonschema。所有JSONL为可读UTF-8且按稳定ID与kind排序；manifest路径相对本目录。结构、引用、源指纹及有限预期均为实际Builder验证，非独立科学审查；不生成SQLite文件。后续模块增加时需要新的包版本与显式依赖manifest，不隐式升级现有记录。
